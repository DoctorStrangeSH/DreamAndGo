# Dream&Go 🚀

Dream&Go — русскоязычная веб-платформа для личных мечтаний, путешествий, коллекций впечатлений и общения с друзьями.

## Главное

**Разрабатываем строго по единому ТЗ v1.0.** Оно фиксирует конечный объём продукта, критерии приёмки, безопасность, тестирование и то, что сознательно отложено.

- [Единое техническое и продуктовое задание](docs/PRODUCT_SPEC.md)
- [План завершения v1.0](docs/DELIVERY_PLAN.md)

Новые идеи не добавляются в текущий релиз автоматически. Всё, что не входит в MUST-объём ТЗ, переносится в backlog после v1.0.

## Локальная разработка

Приложение использует нативные JavaScript ES Modules и Firebase. Для запуска нужен HTTP-сервер; открытие index.html через file:// не поддерживается.

С Node.js 20+:

    python -m http.server 8080

Откройте http://localhost:8080.

Проверки:

    npm test
    npm run check

Для Firebase Emulator и серверных тестов используйте инструкции в соответствующих каталогах.

## Безопасность

Клиентские проверки не заменяют Firebase Security Rules и серверную авторизацию. Не запускайте миграции и не меняйте production rules без резервной копии, dry-run, staging-проверки и rollback-плана. Кандидатные функции и правила в отдельных ветках не считаются production-ready.
