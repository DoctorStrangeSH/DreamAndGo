## Локальный запуск

Приложение использует нативные JavaScript ES Modules и Firebase. Для запуска нужен HTTP-сервер; открытие `index.html` через `file://` не поддерживается.

Например, с Python:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080.

Команды тестирования:

```sh
npm test
npm run check
```

Для проверок не требуются установленные npm-зависимости; используйте Node.js 20+.

## Безопасность

Клиентские проверки не заменяют Firebase Security Rules и серверную авторизацию. Не запускайте миграции и не меняйте production rules без read-only инвентаризации, резервной копии, dry-run, staging-проверки и rollback-плана. Кандидатные функции и правила в отдельных ветках не считаются production-ready.
