# Dream&Go 🚀

Dream&Go — русскоязычный веб-сервис, в котором можно сохранять мечты, путешествия, любимые книги, фильмы и рестораны, общаться с друзьями, получать достижения и отслеживать прогресс.

## Локальная разработка

Приложение использует нативные JavaScript-модули и Firebase (Authentication и Firestore). Для запуска нужен HTTP-сервер: открытие `index.html` через `file://` не поддерживается.

Например, с установленным Python:

```sh
python -m http.server 8080
```

Откройте `http://localhost:8080`. Перед использованием реального Firebase-проекта убедитесь, что домен для разработки разрешён в настройках Firebase Authentication.

```sh
npm test
npm run check
```

Для проверок не требуются установленные npm-зависимости (Node.js 20+).

## Важное перед публичным запуском

- **Firestore Security Rules** должны ограничивать доступ к личным данным владельцем и явно разрешёнными участниками. Правила на сервере нельзя заменить проверками в браузере.
- Проверка уникальности ника сейчас выполняется запросом из браузера и **не является атомарной**. Для строгой уникальности потребуется серверная транзакция/резервирование нормализованных имён.
- Проверьте модуль чата, списки друзей и все места, где данные пользователей подставляются в `innerHTML`. Общий `escapeHTML` применяется постепенно; текущий этап не является полным аудитом XSS.
- Настройте резервное копирование Firestore, политику конфиденциальности, удаление аккаунта и мониторинг ошибок до привлечения большой аудитории.
- Firebase Web API key — публичный идентификатор проекта, а не секрет доступа. Безопасность данных определяется Firebase Rules и настройками авторизации.

## Направления развития

1. Безопасность данных и тесты ключевых пользовательских сценариев.
2. Улучшение регистрации, первого запуска и мобильного интерфейса.
3. Разделение крупных модулей, единый слой доступа к данным, обработка ошибок и состояния загрузки.
4. Публичные страницы, SEO, доступность, аналитика и производительность.
5. CI, preview-развёртывания и проверка релиза перед публикацией.
